# 📋 Student To-Do List

A simple and user-friendly task management application designed for college students to manage their daily academic tasks.

## 🚀 Live Demo

👉 [Open Student To-Do List](https://student-todo-list-3e66xz4sfbhwkkixhyjaqd.streamlit.app/)

## 🛠️ Technologies Used

- Python
- Django
- Django REST Framework
- Streamlit
- SQLite
- REST API
- Git & GitHub
- Render
- Streamlit Community Cloud

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 🔄 Mark tasks as pending
- 🎯 Set task priority
- 📅 Set due dates
- 🔍 Search tasks
- 🔽 Filter tasks
- 📊 Track completion progress
- 📈 View total, completed and pending tasks
